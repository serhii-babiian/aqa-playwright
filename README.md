# aqa-playwright
Automated Smoke Testing with Playwright

Цей проект містить набір автоматизованих Smoke-тестів для перевірки критичної функціональності сайту курсової роботи.

🛠 Стек технологій
Мова: JavaScript
Фреймворк: Playwright
Звіти: Playwright HTML Reporter
CI/CD: Підготовлено до інтеграції з GitHub Actions

📋 Що саме тестується (Scope)
Header & Navigation: Перевірка доступності основних розділів (Home, Favorite) та коректності тексту.

Brand Integrity: Валідація логотипу та іконок соціальних мереж.

UI/UX: Плавний скролінг до футера та перевірка видимості елементів.

Subscription Flow: * Введення даних у форму підписки.

Перевірка валідації (успішна підписка vs існуючий імейл).

Робота з глобальними сповіщеннями (Notification System).
